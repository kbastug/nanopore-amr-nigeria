## Taxonomic classification with Kraken2

Kraken2 was used through two complementary approaches.

### 1. Galaxy-based Kraken2 analysis

Taxonomic classification of successfully assembled contigs was performed using the Galaxy Bioinformatics platform (https://usegalaxy.org).

- Tool: Kraken2 v2.1.3
- Galaxy version: 24.2
- Input: Assembled contigs (FASTA) generated by Flye
- Database: `2025-02-05T2046097_standard_prebuilt_core_nt_2024-0904`
- Confidence threshold: Default
- Taxonomic rank assignment: Default
- Output: Kraken2 taxonomic classification reports and taxon ID assignments used for species identification

### 2. Local Kraken2 analysis on MSI

Kraken2 was also run locally on the Minnesota Supercomputing Institute (MSI).

- Tool: Kraken2 v2.17.1
- Database: PlusPF
- Database build date: May 17, 2021
- Database size: 95 GB
- Input: Assembled genomes or individual contigs
- Output: Kraken2 classification reports and taxonomic assignments

Individual contigs were analyzed separately when assembly results suggested the presence of more than one bacterial taxon.

Example:

```bash
kraken2 \
  --db /path/to/kraken2_db \
  --threads 8 \
  --use-names \
  --report sample.kraken2.report.txt \
  --output sample.kraken2.output.txt \
  sample.fasta

# For samples that did not generate a successful de novo assembly,
# quality-filtered FASTQ reads were analyzed using the local MSI Kraken2 installation.

kraken2 \
  --db /path/to/kraken2_db \
  --report sample_kraken_report.txt \
  --output sample_kraken_output.txt \
  sample_pass.fastq
